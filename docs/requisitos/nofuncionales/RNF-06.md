# RNF-06 — Cobertura de pruebas

## Descripción

El sistema debe mantener una cobertura de código de pruebas automatizadas igual o superior al 80 %.

## Categoría

Mantenibilidad.

## Justificación

Reducir el riesgo de introducir defectos y facilitar el mantenimiento y la evolución del software.

## Versión

v1.0

## Criterio de verificación

Métrica *Line Coverage* igual o superior al 80 %.

## Método de verificación

* Análisis estático de código.

- Pull Request: #6
