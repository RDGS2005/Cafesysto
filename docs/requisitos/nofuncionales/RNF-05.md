# RNF-05 — Modularidad

## Descripción

El sistema debe implementar una arquitectura de módulos que minimice las dependencias entre ellos.

## Categoría

Mantenibilidad.

## Justificación

Poder modificar, desarrollar y probar sus componentes de manera independiente.

## Criterio de verificación

Separación de responsabilidades e independiencia de pruebas.

## Método de verificación

* Análisis estático de código.
* Dependencias entre módulos.
