# RNF-03 — Acceso desde computadoras de escritorio

## Descripción

El sistema debe permitir el ingreso del personal desde computadoras de escritorio.

## Categoría

Portabilidad.

## Justificación

Garantizar que el personal pueda atender los pedidos desde sus dispositivos.

## Criterio de verificación

Funcionamiento del sistema en computadoras de escritorio.

## Método de verificación

* Compatibilidad entre dispositivos.
