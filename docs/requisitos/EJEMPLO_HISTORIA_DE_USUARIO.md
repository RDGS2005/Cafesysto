# RU-01 — Consultar menú

## Descripción

**Como** cliente de la cafetería,  
**quiero** consultar los productos disponibles y sus precios,  
**para** conocer las opciones antes de realizar un pedido.

## Prioridad

Alta

## Versión

v1.0

## Criterios de aceptación

- [ ] El sistema muestra los productos disponibles.
- [ ] Cada producto muestra su nombre y precio.
- [ ] Los productos no disponibles se identifican claramente.
- [ ] El menú muestra información actualizada.

## Reglas de negocio relacionadas

- RN-02: El sistema debe exponer los productos y sus precios.
- Los productos no disponibles no pueden agregarse a nuevos pedidos.
