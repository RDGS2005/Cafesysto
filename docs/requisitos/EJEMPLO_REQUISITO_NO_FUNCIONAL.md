# RNF-01 — Tiempo de respuesta del menú

## Descripción

El sistema debe mostrar el menú de productos en un tiempo máximo de 2 segundos bajo condiciones normales de operación.

## Categoría

Rendimiento.

## Justificación

Garantizar una experiencia de consulta fluida para los clientes.

## Criterio de verificación

Medir el tiempo transcurrido desde la solicitud del menú hasta que la información se encuentre disponible en la interfaz.

## Relación con requisitos funcionales

- RU-01 — Consultar menú.

## Método de verificación

Prueba de rendimiento.
