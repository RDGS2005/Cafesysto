# RFM-03-1 — Actualizar el precio de los productos del menú

## Descripción

**Como** personal de la cafetería,  
**quiero** editar el precio de un producto existente del menú,
**para** mantener el menú actualizado ante la inflación.

## Prioridad

Alta

## Versión

v1.1

## Criterios de aceptación

- [ ] El sistema permite seleccionar un producto existente del menú para su edición.
- [ ] El sistema permite editar el precio del producto.
- [ ] El personal SOLO puede cambiar el precio a un valor numérico mayor a 0.
- [ ] Si el producto se ha actualizado correctamente, el sistema muestra un mensaje de éxito y los cambios se ven reflejados en el menú que ven los clientes (RU-01).

## Reglas de negocio relacionadas

- RN-NEG-04: El precio registrado para un producto en un pedido no cambia si posteriormente se modifica el precio del menú.

## Trazabilidad

- Origen: RU-06
- Issue: #2
- Pull Request: #8
- Casos de prueba: Pendiente

## Observaciones

El sistema no permite cambiar el código ni el nombre de un producto.
